  • {% blocktrans with minutes=policy.grace_minutes %}Arrive within {{ minutes }} minutes of the start. After that the booking is forfeited and other students may take the remaining time.{% endblocktrans %}

{% trans "Application policy (set by the department)" %}

  • {% blocktrans with days=policy.horizon_days %}Bookings open {{ days }} days ahead, including today.{% endblocktrans %}
  • {% blocktrans with minutes=policy.grace_minutes %}Check-in opens at the start of the hour and closes exactly {{ minutes }} minutes later.{% endblocktrans %}
  • {% blocktrans %}A free room can be used immediately for the remainder of the current hour, and always ends at the hour boundary.{% endblocktrans %}
  • {% blocktrans %}You cannot hold two rooms in the same hour, or bookings in adjacent hours.{% endblocktrans %}
  • {% blocktrans with threshold=policy.strike_threshold window=policy.strike_window_days days=policy.auto_suspension_days %}{{ threshold }} unconsumed strikes within {{ window }} days cause one suspension of {{ days }} days.{% endblocktrans %}
  • {% blocktrans %}A strike can only cause one suspension; a suspension does not extend itself.{% endblocktrans %}
  • {% blocktrans %}Scheduled bookings are cancelled without extra penalty when a suspension starts; a session already in use may finish.{% endblocktrans %}

{% blocktrans %}These numeric thresholds are the department's operational defaults, not figures stated in the regulation.{% endblocktrans %}
